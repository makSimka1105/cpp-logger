# C++ snippets pack for faster logging for VScode
Набор снипетов для быстрой вставки debug логов в C++ с множеством шаблонов и навигацией по Tab.

## Возможности

- 🚀 11 готовых шаблонов для различных сценариев логирования
- ⌨️ Быстрая навигация между полями через Tab
- 🎯 Выбор потока вывода (cout/cerr/clog)
- 📊 Логирование контейнеров, указателей, функций
- 🔍 Автоматическое добавление файла, строки, функции

## Установка
1. Для начала клонируем репозиторий:
```
git clone https://github.com/makSimka1105/cpp-logger.git
```
2. Установить .vsix файла :
- Для Linux :

```
code --install-extension ./cpp-logger/cpp-logger-1.0.0.vsix
```
Если не работает code(также для win или mac):
```
# Добавьте VS Code в PATH
cat << 'EOF' >> ~/.zprofile
export PATH="/Applications/Visual Studio Code.app/Contents/Resources/app/bin:$PATH"
EOF

# Перезагрузите shell
source ~/.zprofile

# Теперь установите расширение
code --install-extension cpp-debug-snippets-1.0.0.vsix

```
- Для любой ос через графический интерфейс:

    - Откройте VS Code

    - Нажмите Ctrl+Shift+X (Extensions)

    - Нажмите на три точки ... в верхнем правом углу

    - Выберите "Install from VSIX..."

    - Найдите файл cpp-debug-snippets-1.0.0.vsix

    - Нажмите "Install"



3. Перезагрузите VScode .

В вашем коде наните печатать префикс и выберите нужный снипет

## Основные префиксы:

- `log` / `dlog` - основной debug log с выбором уровня
- `logv` - быстрый лог переменной
- `logenter` - вход в функцию
- `logexit` - выход из функции
- `logline` - лог с файлом и строкой
- `logfname` - лог с именем функции 
- `logif` - условный лог для вкл\выкл отладки
- `logmulti` - лог нескольких переменных
- `logexpr` - лог выражения с результатом
- `logvec` - лог контейнера (vector, array) 
- `logptr` - лог указателя с адресом и значением 


### Пример использования:

1. Напечатайте `log`
2. Выберите из списка автодополнения
3. Используйте Tab для перехода между полями
4. Выбирайте из вариантов, перемещайтесь по полям выбора или вводите свой текст

## Требования

- Visual Studio Code ^1.85.0
- C++ компилятор с поддержкой C++11 и выше
